# KIBO yagona platforma

## Integratsiya
- `index.html` — KIBO EFFECT asosiy platformasi va kirish sahifasi.
- `korean/` — KIBO KOREAN test/o‘qish moduli va uning test HTML sahifalari.
- `vocabulary/index.html` — lug‘at yodlash va takrorlash moduli.
- `dars/`, `api/`, Firebase/Vercel sozlamalari — KIBO EFFECT loyihasidan saqlandi.

## Ishga tushirish
Loyihani mavjud Vercel loyihangizga deploy qiling. Firebase va Vercel environment variables avvalgi sozlamalar bilan bir xil bo‘lishi kerak. Asosiy sahifadagi `KIBO KOREAN` va `Lug‘at yodlash` tugmalari modullarni shu platforma ichida ochadi.

Eslatma: modullar iframe ichida ochiladi; modullarning o‘zidagi Firebase/login sozlamalari va brauzer konsoli orqali deploydan keyin tekshirilishi kerak.
